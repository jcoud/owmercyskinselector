# Конфигуратор косметики — сайт для GitHub Pages

Статическая страница: выбираешь скин / название оружия / цвет оружия,
внизу в закреплённой панели собирается итоговый текст, который можно
скопировать одной кнопкой.

Скины и названия оружия — картинки, кликабельные карточки.
Цвета оружия — просто текстовый список (без картинки на каждый цвет),
плюс один общий скриншот-подсказка сверху вкладки для наглядности.

## 1. Разложите картинки

```
images/
  skins/      <- картинки скинов (то, что скачал fetch_cosmetic_images.py)
  weapons/    <- картинки названий оружия
  VARITANS.png  <- скриншот-подсказка с вариантами цветов (просто для показа)
```

Название каждой карточки берётся из **имени файла** (без расширения).
Например, `images/skins/Seolbim.png` станет карточкой "Seolbim".

## 2. Впишите список цветов оружия

Откройте `build_data.py`, найдите в начале файла:

```python
TEXT_CATEGORY_ITEMS = ["GOLDEN", "JADE", "GALACTIC", "CRIMSON WOLF"]
```

Список уже заполнен вашими вариантами — меняйте, если появятся новые.

Если название скриншота-подсказки другое (не `VARITANS.png`) или он лежит
не прямо в `images/` — поправьте путь в `TEXT_CATEGORY_REFERENCE_IMAGE` там же.

## 3. Соберите data.js

```bash
python build_data.py
```

Пересобирайте каждый раз, когда меняете картинки или список цветов.

## 4. Проверьте локально (по желанию)

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000` и проверьте, прежде чем выкладывать на GitHub.

## 5. Выложите на GitHub Pages

1. Создайте новый репозиторий на [github.com](https://github.com/new)
   (публичный — GitHub Pages для него бесплатен).
2. Загрузите в него **все файлы из этой папки** (index.html, styles.css,
   app.js, data.js, папку images/) — через `git push` или через
   веб-интерфейс GitHub ("Add file" → "Upload files").
3. В репозитории: **Settings → Pages**.
4. "Build and deployment" → "Source" → **Deploy from a branch**, ветка
   **main**, папка **/ (root)** → Save.
5. Через 1-2 минуты появится ссылка вида:
   ```
   https://ваш_логин.github.io/название_репозитория/
   ```

Изменили картинки или список цветов? Пересоберите `data.js` и залейте
изменения в тот же репозиторий — сайт обновится за минуту-две.

## Как устроен итоговый текст

По умолчанию:
```
Скин - Название оружия (Цвет)
```
(любая часть пропускается, если ничего не выбрано в этой категории).

Поле с текстом внизу редактируется вручную прямо перед копированием.
Кнопка **"Сбросить формат"** возвращает текст к автособранному варианту.
